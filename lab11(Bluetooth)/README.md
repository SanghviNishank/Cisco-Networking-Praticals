# Experiment 11: Bluetooth Network

## 1. Aim

Pair a portable music player with Bluetooth speaker(s) in Packet Tracer and verify the connection by playing audio.

## 2. Software and Tools Required

- Cisco Packet Tracer (version not specified).
- A simulated portable music player and Bluetooth speaker(s).
- Bluetooth discovery and pairing controls in Packet Tracer.

## 3. Theory

Bluetooth is a short-range wireless technology for communication between nearby devices. A device discovers another Bluetooth device and establishes a pairing/connection before exchanging data or media. Range and compatibility can affect connection success. This practical does not document IP addressing, a router, or a wired LAN.

## 4. Network Topology

## 5. Configuration and Implementation

1. Open the selected Bluetooth practical in Packet Tracer.
2. Enable Bluetooth on the player and speaker(s).
3. Discover the speaker(s) from the player and pair/connect to the intended device(s).
4. Play audio to test the connection.

Bluetooth profiles, pairing codes, device addresses, and any exact in-file settings are **Not specified in the provided practical files.** The report suggests increasing device range if pairing fails. No Cisco IOS commands or IP configuration are used in the described procedure.

## 6. Testing and Verification

The described verification is audio playback and observation of the speaker connection/state. The report presents OFF and ON result images but does not provide a quantitative test or command output.

## 7. Results

The report illustrates a music player with speaker state shown as OFF and ON and describes playback as the practical test. It does not establish separate measured results for each `.pkt` file; their contents have not been independently run.

- Pair a player with one or more speakers.
